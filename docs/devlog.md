### 오분류 분석

- 불량확률 0.012로, 모델이 거의 확실히 정상이라고 판단
- 사진: 병 입구 안쪽에 가는 선형 이물질
- 가설: 224×224 축소로 가는 선이 소실됨 (미검증)

### 확률 분포 (정상/불량이 얼마나 분리되는가)
| 구분 | 정상 중 불량확률 최대 | 불량 중 불량확률 최소 |
|---|---|---|
| 검증 | 0.01382 | 0.99296 |
| 테스트 | 0.00823 | 0.01201 (놓친 1장) |

### 알게 된 것
- 정확도만 보면 속는다. 불량 재현율이 핵심 지표
- 임계값 0.01은 테스트셋을 보고 고른 값이고, 검증 정상 중 최대값(0.01382)보다 낮아 검증셋에서는 정상 오판이 생김 → 채택하지 않음
- 놓친 사진(0.012)이 정상 확률 구간(~0.014)과 겹쳐 임계값 조정만으로는 해결 불가
- 모델이 확률을 0 또는 1에 가깝게 내놓아(과신) 0.5~0.05 구간 결과가 동일
- 테스트셋은 베이스라인 확인용으로 본 것이며, 임계값은 0.5 유지
